# Synthetic data example

## Overview

This example downloads simulated iterative RNA-FISH experiments generated by
the [StatPhysBio lab](https://labpresse.com/) at ASU and runs the repository's
GPU regression tests without modifying the test code. The tests convert the
simulations to the qi2lab acquisition format, create datastores, preprocess the
images, decode transcripts, and compare the results with ground truth.

You can also run the same workflow in the linked
[Google Colab notebook](https://colab.research.google.com/github/QI2lab/merfish3d-analysis/blob/main/examples/notebooks/Simulation_example.ipynb).

## Requirements

- Linux with a CUDA-compatible NVIDIA GPU and driver
- `git`, `curl`, `unzip`, and `md5sum`
- enough space for the 2.3 GB archive, its extracted contents, and temporary
  datastores created by pytest

Clone the repository, create the project environment, and include the test
dependencies:

```bash
git clone https://github.com/QI2lab/merfish3d-analysis
cd merfish3d-analysis
uv sync --group dev
```

## Download the test data

The test module currently uses this fixed dataset root:

```text
/media/dps/data/merfish3d_analysis-simulation
```

Create its parent directory, download the archived
[simulation data](https://zenodo.org/records/17274305/files/merfish3d_analysis-simulation.zip?download=1),
verify the Zenodo checksum, and extract it:

```bash
sudo mkdir -p /media/dps/data
sudo chown "$USER":"$USER" /media/dps/data

curl -L \
  "https://zenodo.org/records/17274305/files/merfish3d_analysis-simulation.zip?download=1" \
  -o /media/dps/data/merfish3d_analysis-simulation.zip

echo "3c415493ca37bd19af14464badc45fae  /media/dps/data/merfish3d_analysis-simulation.zip" \
  | md5sum --check -

unzip /media/dps/data/merfish3d_analysis-simulation.zip -d /media/dps/data
```

After extraction, the two dataset variants used by the standard test should
have this structure:

```text
/media/dps/data/merfish3d_analysis-simulation/
├── example_16bit_cells/
│   ├── 0.315/
│   │   ├── aligned_1.tiff
│   │   ├── bit_order.csv
│   │   ├── codebook.csv
│   │   ├── GT_spots.csv
│   │   └── scan_metadata.csv
│   ├── 1.0/
│   └── 1.5/
└── example_16bit_flat/
    ├── 0.315/
    ├── 1.0/
    └── 1.5/
```

## Cache the default U-FISH model

The test matrix discovers locally cached U-FISH models during test collection.
Cache the default `smfish` weights once before invoking pytest:

```bash
uv run python -c "from ufish.api import UFish; UFish(device='cuda:0').load_weights(weights_file='finetune_models/v1.0.1-simfish_model.onnx')"
```

The expected cached file is
`~/.ufish/finetune_models/v1.0.1-simfish_model.onnx`. If it is absent, the
standard matrix has no default-model parameter to collect and is skipped.

## Run the standard GPU regression test

Run the test module as-is from the repository root:

```bash
uv run pytest tests/test_simulation_example_pipeline.py -vv
```

No separate pytest GPU option is required. The test constructs the processing
classes with `num_gpus=1`, so CUDA device 0 performs preprocessing and decoding.
The standard matrix covers both dataset variants, all three axial spacings, and
chromatic-aberration estimation enabled and disabled. Each case compares an
affine-only run with a SOFIMA-enabled run and stops if the rounded SOFIMA F1
score is lower.

## Optional exhaustive matrix

The longer feature-prediction threshold sweep is excluded by default. Enable it
explicitly with:

```bash
uv run pytest tests/test_simulation_example_pipeline.py -vv \
  --run-simulation-exhaustive
```

The exhaustive run writes performance records to
`tests/data/simulation_performance.json` unless
`MERFISH3D_PERFORMANCE_REPORT` selects another output path.
